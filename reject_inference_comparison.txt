NOTE: this compares performance on ACCEPTED test data only - it shows whether adding inferred reject labels destabilized the model on data we actually have outcomes for. It cannot confirm the model got any BETTER at predicting rejected applicants specifically, since no true outcome exists for them. A small AUC/KS drop here is common and not automatically bad - it can mean the model is adjusting for a population the accepted-only model never saw. A large drop is a signal the augmentation assumptions (model quality on the 6 shared features, or the fuzzy-weighting method) need review before using this model in production.
